3. Breaking API Changes (Isaac 4.5 → 6.0)

Why these changes are needed: OceanSim was written for Isaac Sim 4.5. Isaac Sim 6.0 renamed or removed several APIs. Without these fixes, the extension fails to load with ImportError or AttributeError.

4. Diff: config/extension.toml

Why: Isaac Sim 6 requires every Python sub-package to have an explicit [[python.module]] entry. The original only registered the two sub-modules (SensorExample, colorpicker) but not the parent packages (isaacsim.oceansim, isaacsim.oceansim.sensors, etc.). Without these, import isaacsim.oceansim.sensors.BarometerSensor fails with ModuleNotFoundError.

Limitations

  • UW_Camera rendering: Requires timeline + render products. Works headless but annotator data may be empty without explicit render step.
